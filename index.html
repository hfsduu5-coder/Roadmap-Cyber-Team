SECTION 01 — PROGRAMMING

CS50 — Harvard University

الكورس الأشهر عالمياً من جامعة هارفارد. يعلمك أساسيات علوم الحاسوب من الصفر بطريقة احترافية. ليس مجرد لغة برمجة — بل تفكير مبرمج حقيقي.

C Python SQL JavaScript HTML/CSS Harvard
  • فهم الذاكرة والأنظمة → أساس الـ Exploitation
  • الخوارزميات وهياكل البيانات → مهم للـ CTF
  • كتابة Scripts بـ Python لتحليل الثغرات
  • Web Security باستخدام JS و HTML
  • مقدمة عن Cryptography
  • شهادة عبر منصة edX باسم Harvard
▶ الكورس الأصلي (EN) ▶ مشروح بالعربية

[ القسم الثاني: نظام كالي لينكس ]

SECTION 02 — KALI LINUX

Kali Linux — الأساسيات

دورة تأسيسية على نظام Kali Linux المخصص للأمن السيبراني. يحتوي أكثر من 600 أداة جاهزة ويُعدّ البيئة الأساسية لكل مختبر اختراق.

Linux Terminal Nmap Wireshark Metasploit Burp Suite
  • تثبيت Kali على VirtualBox / VMware
  • أوامر Terminal الأساسية وإدارة الملفات
  • أشهر أدوات الأمن: Nmap، Wireshark، Hydra
  • Workflow حقيقي لاختبار الاختراق
  • هجمات عملية للمبتدئين + إعداد Lab
▶ مشاهدة الكورس

[ القسم الثالث: الشبكات ]

NETWORKING 01 — CCNA

CCNA — Cisco Certified

لا يمكنك حماية شيء لا تفهم كيف يعمل. CCNA يعطيك "العين" التي ترى بها كل خيط في الشبكة — وهو أساس لا غنى عنه لأي متخصص في الأمن السيبراني.

TCP/IP DNS ACLs VPN Firewall Layer 2
  • Traffic Analysis وفهم البروتوكولات
  • Access Control Lists — أول خط دفاع
  • Device Hardening وتأمين الأجهزة
  • منع هجمات DHCP Snooping و ARP Poisoning
  • أساس للشهادات: CyberOps، Security+، Pentest+
▶ مشاهدة الكورس
NETWORKING 02 — PACKET ANALYSIS

Packet Analysis — تحليل الحزم

هنا تضع الشبكة تحت المجهر. لا تنظر إلى النتيجة فقط — بل تقرأ "النبض" نفسه. تدريب مكثف على Wireshark لتحليل Traffic واكتشاف الهجمات.

Wireshark PCAP Traffic Analysis SOC
  • قراءة ملفات PCAP وتحليل الـ Traffic
  • تمييز الاتصال الطبيعي عن محاولة الاختراق
  • تتبع متى وكيف بدأ الهجوم
  • مهارة أساسية لكل محلل أمني SOC
